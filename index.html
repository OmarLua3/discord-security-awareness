Sebelum memulai

Halaman ini adalah materi edukasi keamanan. Halaman ini tidak meniru halaman login Discord dan tidak meminta atau mengirim password, token, cookie, maupun data akun.

Privasi: jawaban kuis diproses di browser perangkat ini saja. Tidak ada data yang dikirim ke server atau disimpan oleh website.

3 aturan sederhana

  1. Periksa domain secara teliti sebelum membuka tautan.
  2. Jangan pernah membagikan password, token, atau kode autentikasi.
  3. Gunakan autentikasi dua faktor dan laporkan pesan mencurigakan.
